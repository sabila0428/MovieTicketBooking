# Movie Ticket Booking System

A menu-driven **C++ console application** that simulates a movie ticket booking system for a single cinema.

The system allows customers to view movies and shows, check seat availability, book seats, make payments, receive tickets, and cancel bookings.

# Features

*  View movies currently playing
*  View available shows
*  Check seat availability
*  Book one or more seats
*  Make payment for a booking
*  Generate and print tickets
*  Cancel bookings
*  Menu-driven console interface

# Technologies Used

* C++
* Object-Oriented Programming (OOP)
* Standard Template Library (STL)
* Console-based application

# How to Run

Compile the project using a C++ compiler:

```bash
g++ *.cpp -o MovieTicketBooking

Run the program:
### Windows

```bash
MovieTicketBooking.exe
```

### Linux / macOS

```bash
./MovieTicketBooking
```
